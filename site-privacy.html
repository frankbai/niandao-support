网站访问说明

本说明仅涉及本帮助网站，不替代念叨 App 的隐私政策或服务与订阅条款。

网页访问

网站通过 GitHub Pages 托管。页面不设置登录或提交表单，不调用 AI、账号或付款接口，也不包含广告、访问统计脚本、外部字体或 Cookie 设置代码。

GitHub 会为安全目的记录访问者 IP 地址，相关信息由 GitHub 按其规则处理与保存。参见 GitHub Pages 数据收集说明及 GitHub 隐私声明。不将网页本身没有统计脚本理解为托管方不处理访问数据。

邮件联系

点击邮箱链接会打开你的邮件应用，不会自动发送邮件。如果你主动发来邮件，Frank Bai 将使用邮件中提供的邮箱、问题说明及附件答复或处理你的请求。邮件由你所使用的邮件服务与收件邮箱服务传输和保存；请只提供处理请求所需的信息。

需要了解邮件资料的处理方式或请求删除所提供的资料，可联系 frankbxr@126.com。

其他网站链接

访问 Apple、GitHub 等外部链接后，相应网站适用其自己的隐私规则。本网站不接收你的 Apple 账户密码或银行卡资料。
